# Intervalo

Site de uma cafeteria fictícia, criado como projeto de estudo em HTML, CSS e JavaScript. Há páginas separadas para início, cardápio e contato. O cardápio pode ser filtrado por categoria, e o carrinho permite adicionar itens, ajustar quantidades e calcular o total. A conclusão do pedido é uma demonstração: não cobra, não envia nem entrega nada. O formulário de contato valida campos obrigatórios e o formato do e-mail; nenhuma mensagem é enviada.

Para abrir localmente, use `index.html` no navegador. As páginas são `index.html`, `cardapio.html` e `contato.html`. O estilo compartilhado está em `style.css`, os comportamentos em `script.js` e a marca em `logo-intervalo.svg`.
